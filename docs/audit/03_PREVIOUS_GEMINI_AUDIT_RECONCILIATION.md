## 2. Newly Discovered Issues Resolved in This Audit

Beyond the previous 10 items, full-workspace inspection uncovered and resolved **6 additional issues**:
1. **High-Severity Dependency Advisory (`GHSA` / `pnpm audit` ID `1243066` in `zod@4.6.5`):** Upgraded `zod` to `4.6.7` (`pnpm audit` now exits `0` with `No known vulnerabilities found`).
2. **Broken YouTube Iframe Player on `/projects/video/[slug]`:** `extractYouTubeId()` returns `{ videoId, isShort }`, which was interpolated directly into `` `https://www.youtube.com/embed/${ytId}` ``, producing `/embed/[object Object]` on all 5 live video case study pages. Fixed via `resolvePlayableEmbedUrl()`.
3. **Deleted / Unpublished Project Resurrection via Static Fallback:** `getProjectBySlugOrId()` fell back to `PORTFOLIO_DATA.showcaseProjects` whenever a DB row wasn't returned, allowing unpublished/deleted DB projects to remain publicly reachable. Fixed by checking published DB row count before falling back.
4. **Duplicate Project Cards on `/projects` Archive:** `ProjectsPageContent.tsx` re-appended static `PORTFOLIO_DATA.showcaseProjects` items on top of live Supabase projects and re-fetched `/api/projects` on mount despite receiving server-rendered `initialProjects`. Both bugs were eliminated.
5. **Protected Site Modal Ignoring `previewMode: "fallback"` (`Web Wing`):** `ProjectPreviewModal.tsx` initialized `useState<"live" | "summary">("live")`, attempting a broken iframe embed even when `project.previewMode === "fallback"` / `canEmbed === false`. Fixed initialization + added admin selector in `ProjectEditorForm.tsx`.
6. **`SmoothScroll.tsx` Uncancellable `requestAnimationFrame` Leak:** `rafId` only captured frame #1's handle, leaving `lenis.raf` running after unmount. Fixed handle tracking and added `prefers-reduced-motion` bypass.
